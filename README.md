# HTML

Mi primera página web en HTML y CSS, hecha como tarea del curso de Kodland.

## Qué incluye

- Una página estática (`index.html`) con títulos, un párrafo, una lista y una imagen.
- Una hoja de estilos (`style.css`) con fondo azul, texto blanco y dos tipografías: Inter para el texto y Georgia para los títulos.

## Cómo verla

No necesita instalar nada: abre `index.html` en cualquier navegador.

## Estructura

```
index.html  # contenido de la página
style.css   # colores y tipografías
```

La versión siguiente, con un título animado y un widget del clima, está en [HTML2](https://github.com/ItsTuki/HTML2).
